# Fonts

The bundled **stick** alphabet (`grbl_pen_plotter.fonts.stick`) is an original single-stroke Latin + Cyrillic set drawn for this project (Hershey-style plotting strokes). It is **not** taken from Kvenjoy / Kuixiang / VigoWriter vendor archives.

License: MIT with the rest of this repository.

No vendor `.ttf` / proprietary draw fonts are redistributed here.
